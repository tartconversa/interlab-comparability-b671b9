# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

所有方法使用原量纲：efficiency为比例，self_discharge为每日百分比，insulation为兆欧。reported_u是同量纲标准不确定度，不是95%区间。reference_group相同的参考值共享赋值误差，uncertainty为标准不确定度；不是可独立平均掉的误差。运输old_days与测试sequence记录样品经历，destructive为破坏性测试。threshold和tolerance为客户声明的下界与容许测量误差，insulation越高越好，自放电越低越好。方法、量程和样品连接不足时允许未知，输入不含站点排名。

## labs
实证站及运输。

记录键：['lab_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| lab_id | string | 站 |
| methods | string | 支持方法逗号分隔 |
| capacity_daily | integer | 每日台位 |
| transport_days | integer | 寄运日 |

## samples
盲样和留样，数量为可分发单位。

记录键：['sample_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| sample_id | string | 样品 |
| batch_id | string | 产品批 |
| kind | string | 用途 |
| produced | date | 制样 |
| remaining_units | integer | 剩余份 |

## measurements
逐次原始测量，unit_id为同一样品中分出的实物份，破坏后该份不能再测；同父样的重复不独立制造。

记录键：['measurement_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| measurement_id | string | 测量 |
| sample_id | string | 样品 |
| unit_id | string | 实物份 |
| lab_id | string | 站 |
| method | string | 方法 |
| method_version | string | 版本 |
| range_id | string | 量程 |
| sequence | integer | 实物测试顺序 |
| old_days | integer | 制样后天数 |
| value | number | 原读数 |
| reported_u | number | 标准不确定度 |
| destructive | boolean | 破坏 |
| available_at | datetime | 可知 |
